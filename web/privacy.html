Privacy Policy

For the browser extension · Last updated: September 25, 2026

PDF files and network requests

PDF data is parsed locally by the extension. The extension does not upload PDF files to a Fast PDF Viewer server. When you open an online PDF, your browser makes the normal request to the PDF's original server; that server receives the request and network information ordinarily associated with it. A PDF opened from your device is read locally.

Selected-text translation

Translation is sent only after you enable/use translation and select text. The selected text, along with the authentication and prompt needed for the request, is sent directly to the translation provider configured in the extension settings. The extension does not proxy the request. The provider's own privacy, retention, logging, and use practices apply; please review that provider's terms. Model-list requests, if enabled, contact the configured provider and do not upload the PDF.

Local settings and reading progress

  • Your configured API key is stored in the browser's chrome.storage.local. It is not encrypted by the extension and is not synchronized to other devices.
  • Reading progress is stored in the extension page's own localStorage; it is not shared with the ordinary web reader.
  • The extension contains no analytics, advertising, or telemetry code.
  • Uninstalling the extension removes its settings and the reading progress stored by its pages.

Permissions and your controls

The extension requests access to http:// and https:// sites so it can open online PDFs, write a title to the tab that hosts a PDF, and detect PDF responses in older browsers. It does not read webpage text or collect browsing history. Browsers with native PDF takeover use the browser's MIME handling. In older browsers, enabling automatic opening may request optional webRequest permission after you confirm. You can review or revoke site and extension permissions at any time in your browser's extension management settings, and remove the stored API key in the extension settings.

隐私说明

适用于浏览器扩展。

PDF 与网络请求

PDF 数据由扩展在本地解析，扩展不会把 PDF 文件上传到 Fast PDF Viewer 服务器。打开在线 PDF 时，浏览器会向 PDF 原始服务器发起正常请求；该服务器会收到请求及普通网络请求包含的信息。从设备打开的 PDF 在本地读取。

划词翻译

只有在你启用并使用翻译、选中文本后，扩展才会发送翻译请求。选中的文本以及请求所需的身份验证信息和提示词，会直接发送到你在扩展设置中配置的翻译提供商；扩展不代理该请求。提供商自己的隐私、保留、日志和数据使用规则适用，请查看其条款。若启用了模型列表请求，该请求会联系所配置的提供商，但不会上传 PDF。

本地设置与阅读进度

  • API Key 保存在浏览器的 chrome.storage.local 中，扩展不会加密，也不会同步到其他设备。
  • 阅读进度保存在扩展页面自身的 localStorage 中，不与普通网页版共用。
  • 扩展不包含分析、广告或遥测代码。
  • 卸载扩展会清除扩展设置及其页面保存的阅读进度。

权限与用户控制

扩展申请访问 http:// 和 https:// 站点的权限，以便打开在线 PDF、为承载 PDF 的标签页写入标题，并在旧版浏览器中检测 PDF 响应。扩展不读取网页正文，也不收集浏览历史。支持原生 PDF 接管的浏览器使用浏览器提供的 MIME 处理；在较旧浏览器中，启用自动打开时可能会在你确认后申请可选的 webRequest 权限。你可以随时在浏览器扩展管理设置中查看或撤销站点和扩展权限，也可以在扩展设置中删除已保存的 API Key。
