速览 Fast PDF Viewer

隐私说明

这里说明扩展如何处理 PDF、翻译文本、权限和本地数据。

PDF 与网络请求

PDF 字节在本地解析，扩展不会因为打开 PDF 而把文件上传到速览服务器。打开在线 PDF 时，浏览器仍会向 PDF 的原始服务器发起正常请求；原始服务器会按照普通网页请求接收该请求及其自身需要的网络信息。

划词翻译

只有在你启用翻译并选中文本后，选中的文本才会发送到你在设置中配置的翻译提供商。速览不代替该提供商处理请求， 具体数据处理方式以你选择的提供商为准。

本地设置与阅读进度

  • API Key 保存在浏览器的 chrome.storage.local 中，未加密，也不会同步到其他设备。
  • 扩展不包含分析、广告或遥测代码。
  • 扩展内的阅读进度保存在扩展自身同源的 localStorage 中，不与普通网页版共用。
  • 卸载扩展会清除扩展设置以及扩展页面保存的本地阅读进度。

自动打开 PDF 与主机权限

支持原生 PDF 接管的浏览器使用浏览器提供的 MIME 处理能力，不需要 webRequest 或所有网站的访问权限。 较旧浏览器若不支持原生能力，启用自动打开时才会在用户确认后申请 webRequest 以及 http://*/*、https://*/* 主机权限，用于检测 PDF 响应并交给阅读器；该回退路径不读取网页正文。
